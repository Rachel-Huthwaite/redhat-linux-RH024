# 03 - Fun Learning Answers: Documentation

Use these answers to check your responses from `03-FunLearningQuestions.md`.

---

### Answers

1. **Local Availability:**
   * They are stored locally on your Linux system and do not require an active internet connection[cite: 3].

2. **Exiting man:**
   * Press `q`[cite: 3].

3. **Searching Text:**
   * Type `/` followed by your search keyword (e.g., `/options`)[cite: 3].

4. **Navigating Matches:**
   * Press `n` to go to the next match (or `N` to go to the previous match)[cite: 3].

5. **Configuration Files:**
   * Yes, `man` pages document both executable commands and system configuration file formats[cite: 3].

6. **Self Documentation:**
   * `man man`[cite: 3].
