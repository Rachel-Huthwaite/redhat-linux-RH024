# Fun Learning

This package is where I turn course theory into activities and quizzes I
build for myself.

The method comes from a study tactic I picked up in high school: instead of
just writing notes on theory, write out the *questions* that theory would
naturally raise — then answer them. It forces active recall instead of
passive re-reading, and it's the single tactic that made the biggest
difference to my comprehension once I started using it. I'm applying it here for
the same reason.

Each entry in this package will typically:

- Be tied to a specific lesson (see [`../LessonBreakdowns`](../LessonBreakdowns))
- Pose a handful of self-written questions covering that lesson's key
  concepts

Files are added per lesson as I go.
