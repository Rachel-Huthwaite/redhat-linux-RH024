# 06 - Fun Learning Quiz: Basic File Management

Test your active recall on the concepts introduced in Lesson 06.

---

### Questions

1. **Listing Details:** What flag combination displays a detailed directory listing with human-readable file sizes, including hidden files?
2. **Hidden File Convention:** How are hidden files identified in a Linux filesystem?
3. **Directory Creation:** What does the `-p` flag do when used with `mkdir`?
4. **Verbose Feedback:** What additional output does `mkdir -pv` provide when creating directory structures?
5. **Creating Files:** What command creates an empty file without needing a text editor?
6. **Renaming vs. Moving:** How does the single command `mv` handle both moving a file and renaming a file?
7. **Directory Removal:** What flag must be passed to `rm` to delete a non-empty directory and its contents?
8. **Safety Safeguards:** How does appending the `-i` flag to `rm` protect against accidental file deletion?
