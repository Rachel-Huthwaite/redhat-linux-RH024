# 02 - Fun Learning Quiz: Introduction to Shell

Test your active recall on the concepts introduced in Lesson 02.

---

### Questions

1. **Shell Definition:** What is the primary role of a shell in a Linux system?
2. **Command Structure:** What are the three primary components that make up a standard Linux command line?
3. **Option Formats:** How do short options differ from long options in terms of command syntax?
4. **Disk Usage Tool:** In the command `du -sh /home/user`, identify the command, the options, and the argument.
5. **Human-Readable Output:** What does the `-h` option typically do when appended to commands like `du`?
6. **Tab Autocompletion:** What happens when you press `Tab` twice after partially typing a command or subcommand?
7. **Finding Documentation:** Which built-in command provides the full system manual page for terminal commands?
8. **Command Flexibility:** Do all Linux commands require both options and arguments to execute properly?
