### Questions

1. **Checking Registration:** What command checks whether your system is registered with Red Hat Subscription Management?
2. **Network Architecture:** How does internet connectivity requirements differ for client servers updating directly from the Red Hat CDN versus updating through Red Hat Satellite?
3. **Automated Installation:** What flag appended to `dnf install` automatically accepts all confirmation prompts during installation?
4. **Errata Types:** Name the three types of Red Hat Errata advisories (RHBA, RHEA, RHSA) and state what each addresses.
5. **Vulnerability Tracking:** What does CVE stand for, and what system provides a 0.0 to 10.0 rating scale for vulnerability severity?
6. **Inspecting Advisories:** Which command lists available security advisories affecting installed system packages?
7. **Selective Security Updates:** How do you execute a `dnf` update that applies only `Important` and `Critical` security advisories?
8. **Reboot Verification:** What exact command checks if recent package updates require a system reboot?
