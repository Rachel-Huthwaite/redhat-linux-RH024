# 05 - Fun Learning Quiz: Linux Directories Explained

Test your active recall on the concepts introduced in Lesson 05.

---

### Questions

1. **Root Directory:** What single character represents the root directory in a Linux filesystem?
2. **Current Location:** Which command prints the absolute path of your current working directory?
3. **Shortcut Navigation:** What happens if you run the `cd` command without passing any arguments or options?
4. **Hidden Files:** What option flag must be passed to `ls` to display hidden files and directories?
5. **System Settings:** In which directory do system-wide configuration files live, and what best practice should you follow before modifying them?
6. **Data Storage Comparison:** How does data persistence differ between `/tmp` and `/var`?
7. **Executables & Libraries:** Where do standard system binaries and 64-bit shared library files live within `/usr`?
8. **Mounting:** What is the purpose of the `/mnt` directory?
9. **Runtime State:** Why is the `/run` directory cleared and recreated fresh on every reboot?
10. **Administrative Home:** What is the difference between `/home` and `/root`?
