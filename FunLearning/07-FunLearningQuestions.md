# 07 - Fun Learning Quiz: Editing Files with Vim

Test your active recall on the concepts introduced in Lesson 07.

---

### Questions

1. **Default Mode:** What mode is active when you first open a file using `vim filename.txt`?
2. **Switching to Insert Mode:** Which key do you press to enter Insert mode, and how can you confirm you are in Insert mode?
3. **Returning to Normal Mode:** What key returns you to Normal mode from any other mode?
4. **Copy & Paste Shortcuts:** What keystroke copies (yanks) an entire line in Normal mode, and what keystroke pastes it?
5. **Multiple Pastes:** How would you paste a yanked line 10 times consecutively using a single command?
6. **Undo & Redo:** Which key undoes your last change in Normal mode, and what key combination redoes it?
7. **Force Quitting:** What Command mode entry allows you to quit Vim immediately without saving changes?
8. **Interactive Practice:** What built-in shell command launches an interactive step-by-step tutorial for learning Vim?
