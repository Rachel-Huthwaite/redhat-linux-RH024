# 09 - Fun Learning Quiz: File Permissions

Test your active recall on the concepts introduced in Lesson 09.

---

### Questions

1. **Permission Values:** In octal notation, what numerical values correspond to Read (`r`), Write (`w`), and Execute (`x`) permissions?
2. **Directory Execution:** What specific operation does Execute (`x`) permission allow when assigned to a directory versus a file?
3. **Octal Decoding:** Translate the octal permission `640` into symbolic notation (e.g., `rw-r-----`).
4. **Inspecting Directories:** What command and flag combination displays the permissions of a directory itself rather than its inner contents?
5. **Extreme Modes:** What does running `chmod 000 filename` do to a file's access rights?
6. **Ownership Changes:** What `chown` command syntax changes both the owner (`john`) and the group (`devs`) on a file named `app.py` simultaneously?
7. **Evaluation Order:** In what precise order does Linux check file permissions when a user attempts to access a file?
8. **Security Principles:** Explain the Principle of Least Privilege as applied to Linux file permissions.
9. **Terminal Multiplexing:** What primary operational benefit does using `tmux` provide when working over remote SSH connections?
