# 03 - Fun Learning Quiz: Documentation

Test your active recall on the concepts introduced in Lesson 03.

---

### Questions

1. **Local Availability:** Where are `man` pages stored and accessed—locally on the machine or over an internet connection?
2. **Exiting man:** What key do you press to exit a `man` page viewer and return to your terminal prompt?
3. **Searching Text:** What character do you type to initiate a keyword search inside a `man` page?
4. **Navigating Matches:** Once a search term is entered in a `man` page, which key jumps to the next occurrence of that keyword?
5. **Configuration Files:** Can `man` pages be used to inspect documentation for configuration files, or are they strictly for commands?
6. **Self Documentation:** What command would you type to view the manual page for the `man` program itself?
