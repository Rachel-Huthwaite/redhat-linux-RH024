### Answers

1. **Ecosystem Pipeline:**
   * Open Source Community Projects $\rightarrow$ Fedora Linux $\rightarrow$ CentOS Stream $\rightarrow$ Red Hat Enterprise Linux (RHEL)[cite: 1].

2. **Distro Core:**
   * The **Linux Kernel**[cite: 1].

3. **Distribution Differences:**
   * System default configurations, included applications/tools, package managers, user experience/desktop environments, and release schedules[cite: 1].

4. **Package Management:**
   * **RPM (Red Hat Package Manager)**[cite: 1]. It is incompatible with `apt` because `apt` uses Debian (`.deb`) package structures and database indexes, whereas RPM uses its own binary package format and metadata[cite: 1].

5. **Role of CentOS Stream:**
   * CentOS Stream serves as a continuously updated upstream preview channel for the next minor release of RHEL, allowing community members and developers to test and contribute code directly to future RHEL updates[cite: 1].

6. **Filesystem Standards:**
   * **Filesystem Hierarchy Standard**[cite: 1]. Red Hat adheres to it to maintain strict predictability, system reliability, and consistent file locations for software and system administrators across machines[cite: 1].

7. **RHEL Lifecycle:**
   * Major releases occur every 3 years with a total 10-year lifecycle[cite: 1]:
     * **Full Support Phase (Years 1–5):** Feature enhancements, bug fixes, software updates, and hardware support[cite: 1].
     * **Maintenance Support Phase (Years 6–10):** Focuses strictly on critical security patches and high-severity fixes[cite: 1].

8. **Upstream Contributions:**
   * Any two of: **systemd**, **KVM**, or **TuneD**[cite: 1].

9. **Developer Subscription:**
   * Up to 16 systems (production or non-production use), access to system updates, and self-service Red Hat Knowledgebase support[cite: 1].

10. **System Upgrades:**
    * **Leapp** (`leapp`)[cite: 1].
