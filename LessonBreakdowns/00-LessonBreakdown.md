# Lesson Breakdowns

This package contains a breakdown of every video in the RH024 course, one
file per lesson, documented as I work through them.

Each lesson file follows the same structure so they stay easy to scan and
compare over time:

1. **Overall Summary** — what the video covered, in my own words
2. **New Jargon** — new terms introduced (also rolled up into
   [`../CommandsAndJargon/Jargon.md`](../CommandsAndJargon/Jargon.md))
3. **Commands Learnt** — new commands, with what they do (also rolled up
   into [`../CommandsAndJargon/Commands.md`](../CommandsAndJargon/Commands.md))
4. **Key Concepts** — the ideas the lesson was actually trying to teach
5. **Main Notes** — anything else worth capturing
6. **My Key Learning** — the one or two things I'll actually carry forward

Files are named by lesson number and title, e.g. `01-linux_distributions.md`.

*(This structure is a first draft — expect it to get refined once the first
real lesson is written up.)*
