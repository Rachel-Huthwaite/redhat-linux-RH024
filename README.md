# Red Hat Linux Administration — Learning Journey (RH024)
My public learning log for Red Hat's RH024 course: lesson breakdowns, a growing Linux command/jargon glossary, and real Fedora troubleshooting stories.

## How to read this repo

1. Start with [`PersonalMotivation/`](./PersonalMotivation) — why I'm doing
   this, and my actual lived experience switching to Linux (Fedora) before
   starting the course.
2. [`LessonBreakdowns/`](./LessonBreakdowns) — a structured summary of every
   video in the course, one file per lesson.
3. [`CommandsAndJargon/`](./CommandsAndJargon) — a running glossary of every
   command and term I pick up.
4. [`FunLearning/`](./FunLearning) — self-made quizzes and exercises, the
   study method that's worked best for me since high school.
