# Personal Motivation

## Why I'm doing this course

I run [Fedora Linux](../CommandsAndJargon/Jargon.md#fedora-linux) as my daily
driver, and Fedora sits directly upstream of RHEL in the Red Hat ecosystem —
it's where a lot of what eventually lands in RHEL gets tried out first. So
when the chance to take RH024 came up, it was an easy yes for two reasons:

1. **Practical curiosity.** I wanted to know whether a course built around
   RHEL would actually teach me things that carry over to the OS I use every
   day — package management, systemd, networking, permissions — or whether
   the enterprise side of Red Hat would feel disconnected from my own
   desktop. So far, it's carried over far more than I expected.
2. **Wanting to go deeper.** I switched from Windows to Fedora specifically
   to understand my system properly, not just use it. This course is a
   structured way to keep pushing on that — filling in the gaps I've hit
   while self-teaching, and getting the "why" behind commands I'd already
   started using by trial and error.

## What this looks like in practice

A lot of what I document in [`LessonBreakdowns/`](../LessonBreakdowns) ends
up getting tested on my own Fedora setup shortly after — this repo is as
much a record of "does this apply to my machine too?" as it is a record of
the course itself.
